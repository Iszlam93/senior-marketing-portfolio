# Islam Elsaeed — Senior B2B Marketing Portfolio

A single-page portfolio built to show the work behind the numbers: go-to-market
strategy, partner and channel marketing, demand generation, and the AI-enabled
workflows I use to scale it.

**Live site:** https://islam-elsaeed-b2b-portfolio.islam-elsaid.chatgpt.site
**Contact:** [Islam-elsaid@outlook.com](mailto:Islam-elsaid@outlook.com) · [LinkedIn](https://www.linkedin.com/in/islam-el-saeed)

## What's inside

- **Selected campaigns** — Companial Enterprise Membership launch, the ISV
  Partner Program, LEAP's launch campaign, and the Fi Global webinar series,
  each with ownership scope, evidence links, and results.
- **Lead generation** — a full campaign-to-CRM-opportunity funnel from Global
  Connect 2026, plus portfolio-wide demand metrics (143+ leads, 50+
  opportunities, 6.6× campaign ROI, 44.68% email open rate).
- **Data & email marketing** — how audience data compounded across three
  roles, from a cold launch list to segmented nurture journeys.
- **AI workflow prototype** — a designed (Impact Day) system for turning 20
  manual webinar workflows into one Asana + Claude pipeline, labeled
  transparently as a prototype with projected impact.
- **Marketing operating stack** — the tools behind the work: Asana, Eloqua,
  Dynamics 365, ON24, GA4, LinkedIn Campaign Manager, and the AI tools used
  day to day.

## Stack

Built on [vinext](https://github.com/cloudflare/vinext) (Next.js on
Cloudflare Workers) with Tailwind CSS. This repo is the source of record;
the live deployment runs on Cloudflare.

```bash
npm install
npm run dev      # local development
npm run build    # verify the production build
```

Requires Node.js `>=22.13.0`.
